ERANOS vs Serpent

Checking a fast code against a slow, exact one, so an optimizer could run thousands of times.

Monte Carlo codes like Serpent are accurate but slow. An optimizer has to evaluate thousands of core designs, so it needs a fast code you can trust.

I used Serpent as the reference and ran ERANOS with different TGV/VARIANT transport options and a 7 energy group structure. P3 transport with 7 groups agreed best with Serpent. The 7-group structure cut calculation time with little loss in precision, which made it possible to run thousands of evaluations per optimization.
