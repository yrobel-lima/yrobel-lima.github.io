Fuel shuffling

Python optimizers that decide where each fuel assembly goes in the ALLEGRO core.

Where each fuel assembly sits changes how long the reactor can run. Every arrangement also has to respect limits on power peaking factor, excess reactivity and linear heat generation rate. There are far too many arrangements to try one by one.

I coupled a Python optimization system to ERANOS 2.3 and tried two methods. With genetic algorithms, arrangements are bred like organisms, and the PMX crossover found the best core twice as fast as OX. Tabu search keeps a memory of recent moves so it doesn't settle on an arrangement that is only good. I wrote a new ERANOS procedure to swap the assemblies.

The best arrangements improved fuel cycle performance by 15%.
