Website assistant

Helps people on the website find the right clinician or service.

People on a clinic website often don't know which clinician or service fits what they need. Those questions used to go to the admin team.

It is a multi-agent system in Python, built with the OpenAI Agents SDK and running on Microsoft Foundry. It answers the visitor's questions and points them to the right clinician or service. The matching rules were checked by the clinicians themselves.

  • Python
  • OpenAI Agents SDK
  • Microsoft Foundry
