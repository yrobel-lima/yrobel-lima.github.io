Clinical toolkit

One web app with four AI tools for clinicians and staff, written entirely in Python.

  • Session transcripts into completed WorkSafeBC report forms as PDFs. This cut clinicians' after-hours documentation by more than half.
  • Session transcripts scored against a rubric, with the results saved to Dataverse.
  • Clinical reports reviewed against a checklist, with the review saved to SharePoint and sent by email.
  • Research papers summarized, tagged and posted to the right Slack channel.

Every tool follows the same pattern. The user uploads a file or fills in a form, Azure OpenAI drafts the output, and Pydantic validates it against a schema. The user reviews and edits the draft before submitting it, and every action is logged without patient content.

The app is one NiceGUI process on FastAPI, so there is no separate frontend. It stores data in Dataverse and SharePoint, sends email through Microsoft Graph, fills PDF forms with PyMuPDF and builds reports from Word templates with docxtpl. PDF generation runs in a worker thread so it never blocks the event loop. Staff sign in with Microsoft Entra ID, and the app ships as a Docker image to Azure App Service.
