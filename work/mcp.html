MCP server

Gives every agent the same tools and one controlled way into internal data.

Each new agent needed its own way into internal tools and data. Rebuilding that for every agent is slow and hard to keep secure.

I wrote an MCP (Model Context Protocol) server in Python with FastMCP. Agents written in Python and agents built in Copilot Studio now call the same tools through it.
